## 2026-05-06 首页网格布局修复

### 问题：首页卡片"缩在角落很小"
- 根因：`Layout.astro` 的 `updateMainGridCols()` 函数只检查 `data-sidebar-position` 属性，未判断侧边栏是否启用
- `sidebarConfig.enable = false` 但 `position = "both"` → JS 把 `#main-grid` 改成了三列侧边栏布局，内容区被压缩到 280px
- 服务端渲染正确（grid-cols-1），但客户端 JS 在 `astro:page-load` 时覆盖了 grid 类

### 修复
1. **PostPage.astro** CSS：网格从 `auto-fill minmax(200px, 1fr)` 改为固定列数
   - 移动端 (<768px)：`grid-template-columns: repeat(2, 1fr)` + gap 0.5rem
   - 桌面端 (≥768px)：`grid-template-columns: repeat(4, 1fr)` + gap 0.75rem
2. **siteConfig.ts**：`postsPerPage` 从 10 改为 20（4×5=20）
3. **Layout.astro** `updateMainGridCols()`：增加侧边栏禁用判断，读取 `#grid-class-carrier` 的 `data-grid-class`，如果服务端渲染时就是 `grid-cols-1`（无侧边栏），则不做任何修改并清理可能被错误添加的侧边栏 grid 类

### 验证结果（Playwright）
- 桌面端 1920×1080：main-grid 1568px 单列，卡片 4 列 383px/列 ✓
- 移动端 375×812：卡片 2 列 177px/列 ✓
